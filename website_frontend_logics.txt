signer_details.html
Title: DAD – Signer Details
Purpose: View and edit a signer's profile and signing limit authorizations.
         Also displays DADREQ change request details in read-only mode.

URL Parameters:
  • upn: Signer's email/UPN (used for audit link and export).
  • action: If "update", enters edit mode on load.
  • reqid: If contains "DADREQ", enters DADREQ read-only mode.
  • mode: If "approval1", makes Approval 1 Result (dropdown) and Approval 1 Note (text input) editable.
          If "approval_tsa", (future) makes TSA Result and TSA Note editable.

Action Bar (3 modes):
  1. View Mode: Request Update | Refresh | Export | Print | View Audit Log (→ audit_signer.html?upn=...)
  2. Edit Mode: Submit for Review | Cancel
  3. DADREQ Mode: Refresh | Export | Print

Table 1 – Signer Profile (detail-table, read-only):
  Fields:
    • GAD ID
    • Last Name
    • First Name
    • Business Unit
    • Signers Cost Center
    • Job Level / Job Grade
    • Job Title
    • Employee No.
    • Pickup Cheques
  Data source:
    • Existing Signer (gad_id exists in signer table):
        Query: signer LEFT JOIN wd_user_profile, infor_business_unit, wd_job_level
        All fields populated from signer + wd_user_profile lookups.
    • New Signer (gad_id NOT in signer table):
        Query: wd_user_profile LEFT JOIN wd_job_level
        Populates: GAD ID, Last Name, First Name, Cost Center, Job Grade, Job Title, Employee No.
        Defaults: Business Unit=(dropdown from infor_business_unit.name), Pickup Cheques=N, Temporary=N, Status=Inactive.
  In edit mode: Business Unit, Pickup Cheques, and Status are editable via dropdowns.
  In DADREQ mode: Changed profile fields show original value → arrow → new value (yellow highlight).

Table 2 – Signing Limit Authorizations (editable in edit mode):
  Columns:
    • Delete Row (hidden column, shown in edit mode — contains "X" button)
    • Countries (Territories)
    • Policy Category
    • Limit Amounts
    • Currency
    • Approval Cost Center
    • Exception (Y/N)
    • Temporary (Y/N)
    • Temporary Start Date
    • Temporary End Date
    • Business Rationale (free text)
    • Business Controls (free text)
    • System
    • Accounts Restriction

  Allowed dropdown values per column (used in edit mode):
    • Countries: from wd_territory (datalist)
    • Policy Category: from gdas_policy (datalist)
    • Limit Amounts: number input (no dropdown)
    • Currency: from infor_currency (datalist)
    • Approval Cost Center: from infor_cost_center (datalist)
    • Exception: Y, N (select)
    • Temporary: Y, N (select)
    • Temporary Start Date: date input
    • Temporary End Date: date input
    • Business Rationale: free text input
    • Business Controls: free text input
    • System: AP, SNOW, Concur (select)
    • Accounts Restriction: free text input

Logic – Edit Mode:
  - enterEditMode(): 
      • Shows New Row button.
      • Swaps action bar to Submit for Review | Cancel.
      • Shows the "Delete Row" column.
      • Converts all table cells into editable inputs (number input for Limit Amounts,
        text input with datalist for all other columns).
      • Stores original row data in originalData array for comparison and cancel/restore.
      • Attaches input listeners: if value differs from data-orig, highlights cell yellow.
  - exitEditMode() / cancelEdit():
      • Restores original data from originalData array, removes new rows.
      • Hides Delete column, restores view action bar.
  - deleteRow(btn): If row status is "new", removes it from DOM. If "original", hides
    it and marks data-status="deleted".
  - addNewRow(): Appends a new row with all editable inputs (empty defaults).
    Attaches same change-highlight listeners.
  - reviewChanges(): Opens a modal showing a summary table of all changes:
      • Deleted rows: shown with red background, line-through text, label "Deleted".
      • New rows: shown with green background, all cells yellow-highlighted, label "New".
      • Updated rows: shown as Before/After pairs — Before row is greyed out,
        After row highlights changed cells in yellow bold.
      • If no changes detected, shows "No changes detected" message and hides
        Confirm Submit button.
  - confirmSubmit(): Placeholder alert — "Changes submitted to backend API." Then reloads.

Logic – DADREQ Mode (read-only change review):
  - Activated when URL has ?action=view_request or ?action=approval1
  - Hides view actions, shows DADREQ actions (Refresh | Export | Print).
  - Shows DADREQ badge next to Signer Profile title.
  - applyDADREQView(changes): Reads change definitions from dadreqChanges object:
      • Profile changes: Appends "→ new value" with yellow highlight next to original value.
      • Limit changes: Inserts a "Change Type" column. For each change:
          - "update": Shows original row labeled "Change (Before)" and a new row below
            labeled "Change (After)" with changed cells in yellow. Thick borders group them.
          - "delete": Marks row with red background, line-through, labeled "Removal".
          - "new": Appends new row with purple label "Additional", all cells yellow.
          - "nochange": Green background, labeled "No Change".

report.html
Title: DAD – Reports and Extracts
Purpose: Filter signer data by exactly one criterion and display/export matching records.

Action Bar: Print

Filter Panel (shown by default):
  Fields (all dropdowns except Limit Amounts):
    • Business Unit (select: list of 10 business units)
    • Signer Cost Center (select: 1010, 2020, 3030, 4040, 8352, T08)
    • Job Level / Job Grade (select: Level 4 through Level 10)
    • Pickup Cheques (select: Y | N)
    • Countries (select: NA, US, HK)
    • Policy Category (select: EXP, PAC, EXT)
    • Limit Amounts (max) (number input, min 0)
    • Currency (select: CAD, USD, HKD)
    • Approval Cost Center (select: 1010, 2020, 3030, 8352, T08)
    • System (select: AP, SNOW, Concur)
  Buttons: Apply | Clear
  Validation: Error message shown if user selects ≠ 1 filter.

Results Table (hidden until Apply, top 50 rows):
  Columns: GAD ID | Last Name | First Name | Business Unit | Signers Cost Center |
           Job Level / Job Grade | Job Title | Employee No. | Pickup Cheques |
           Countries | Policy Category | Limit Amounts | Currency |
           Approval Cost Center | Exception | Temporary | Temporary Start Date |
           Temporary End Date | Business Rationale | Business Controls | System |
           Accounts Restriction
  Button: Export all data

Logic:
  - handleFilterChange(el): When a filter is selected, ALL other filter fields are hidden
    (display:none on their .filter-field container) to enforce the single-filter rule.
    When cleared, all fields re-appear.
  - applyFilter(): Counts how many filters have a non-empty value.
    If count ≠ 1, shows error message "Please select exactly one filter before applying."
    and hides the results panel.
    If count = 1, filters the 50 dummy rows by the active filter and renders matching rows.
  - clearFilters(): Resets all filter values, re-shows all filter fields, hides results panel.
  - Dummy data: 50 rows generated by cycling through arrays of names, business units, cost
    centres, job levels, etc. Sorted by Business Unit ascending.
  - exportCSV(): Builds CSV from visible table rows, triggers file download as
    "signer_report_extract.csv".
  - Print style: landscape, hides nav/action bar/search panel.

upload.html
Title: DAD – Upload Tool
Purpose: Bulk data operations — download signer data or upload CSV changes.

Action Bar: Refresh

Upload Items (5 operations):

  1. Download All Signer Data
     • Button: "Download All Signer Data"
     • CSV columns: GAD ID, Approval ID, Countries (Territories), Policy Category,
       Limit Amounts, Currency, Approval Cost Center, Exception, Temporary,
       Business Rationale, Business Controls, System, Accounts Restriction

  2. Disable / Enable Signers
     • Button: "Download Template File" (CSV with columns: Action (Enable/Disable), GAD ID)
     • Button: "Upload Changes" + file input (accepts .csv, .xlsx)
     • Status message area

  3. Update Signer Approval Data
     • Button: "Download Template File" (CSV with columns: Approval ID, Countries (Territories),
       Policy Category, Limit Amounts, Currency, Approval Cost Center, Exception, Temporary,
       Business Rationale, Business Controls, System, Accounts Restriction)
     • Button: "Upload Changes" + file input
     • Status message area

  4. Add Signer Approval Data
     • Button: "Download Template File" (CSV with columns: GAD ID, Countries (Territories),
       Policy Category, Limit Amounts, Currency, Approval Cost Center, Exception, Temporary,
       Business Rationale, Business Controls, System, Accounts Restriction)
     • Button: "Upload Changes" + file input
     • Status message area

  5. Delete Signer Approval Data
     • Button: "Download Template File" (CSV with columns: GAD ID, Approval ID)
     • Button: "Upload Changes" + file input
     • Status message area

Logic:
  - downloadCSV(filename, columns): Creates a CSV file with only the header row (column names),
    generates a Blob, and triggers a browser download.
  - handleUpload(inputId): Checks if a file is selected in the corresponding file input.
    If no file: shows red error "Please select a file first."
    If file selected: shows green success message with filename. (Demo only — no actual upload.)

dashboard.html
Title: DAD – Dashboard
Purpose: Summary view with KPI cards and three data tables showing request status, signer changes, and exceptions.

Action Bar: Refresh | Print

KPI Cards (values loaded from database):
  • Requests Submitted
  • Requests Approved
  • Signers with Updated Job Level
  • Inactive Signers
  • Cost Centres Inactivated / Recycled

Table 1 – Request Status (Past 90 days):
  Columns: Request ID | Date Submitted | Submitted By | Submitted For |
           Approval (AVP+) | Approval (TSA) | Request Status
  Filter: Request Status dropdown (All / Open / Complete / Reject)
  Button: Export all data (CSV export)

Table 2 – Signer Change (Past 90 days):
  Columns: GAD ID | First Name | Last Name | Action | Old Status | New Status |
           Changed By | Change Date
  Filter: Action dropdown (All / INSERT / UPDATE / DELETE)
  Button: Export all data (CSV export)

Table 3 – Signers with Exception (TOP 50):
  Columns: GAD ID | Status | Employee No. | First Name | Last Name |
           Business Unit | Currency | Limit Amounts | Approval Cost Centre |
           Policy Category | System | Cheque Pick Up | Exception
  Button: Export all data (CSV export)

Logic:
  - Data loaded from database via sql.js.
  - exportTable(tableId, filename): Extracts all visible rows from a table as CSV,
    creates a Blob download link, and triggers download.
  - Print style: landscape layout, hides nav/action bar.

Data mapping:
