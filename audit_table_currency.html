DEV Note – Search Audit Log (table=audit_infor_currency)

Filter Fields:

Change Date    = audit_infor_currency.change_date (exact match)
Change Type    = audit_infor_currency.action (exact match: INSERT/UPDATE/DELETE)
Changed By     = audit_infor_currency.change_by (LIKE)
Currency Name  = old_name OR new_name (LIKE)
Status         = old_status OR new_status (BIT match)

Behavior:

Apply Filter re-queries database with SQL WHERE clauses, returns TOP 50.
Clear resets all filters and re-queries TOP 50 unfiltered.
Enter key triggers filter from any input field.

DEV Note – Audit Log: Currencies (table=audit_infor_currency)

Fields Mapping:

Change Date    = audit_infor_currency.change_date
Change Type    = audit_infor_currency.action
Changed By     = audit_infor_currency.change_by
Row            = Before / After / New / Deleted label
Currency Name  = old_name / new_name
Status         = old_status / new_status

Display Rules:

Source: audit_infor_currency table
Display: TOP 50 audit groups (SQL LIMIT 50, sorted by change_date DESC, id DESC)
Filtering: Re-queries DB with WHERE clauses, returns TOP 50 of filtered results
Export: Runs same query WITHOUT LIMIT, exports all matching rows to CSV

Row Styles:

INSERT = green background, green badge, "New" label
UPDATE = Before (grey text) / After pair, yellow highlight on changed cells
DELETE = red background, red badge, strikethrough text, "Deleted" label
