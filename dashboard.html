DEV Note – Request Status (Past 90 days) (key=req_signer.id)

Fields Mapping:

Request ID     = req_signer.id
Date Submitted = req_signer.req_date
Submitted By   = req_signer.submitter
Submitted For  = req_signer.gad_id
Approval (AVP+) = req_signer.approver1_result (NULL=Pending, 0=Rejected, 1=Approved)
Approval (TSA)  = req_signer.approver2_result (NULL=Pending, 0=Rejected, 1=Approved)
Request Status = req_signer.new_status (NULL=Pending, 0=Rejected, 1=Approved)

Approval:

AVP Result     = req_signer.approver1_result (NULL=Pending, 0=Reject, 1=Approve)
AVP Note       = req_signer.approver1_note
TSA Approver   = req_signer.approver2_gad_id
TSA Result     = req_signer.approver2_result (NULL=Pending, 0=Reject, 1=Approve)

DEV Note – KPI Cards

Requests Submitted             = SELECT COUNT(*) FROM req_signer
Requests Approved              = SELECT COUNT(*) FROM req_signer WHERE new_status = 1
Signers with Updated Job Level = SELECT COUNT(DISTINCT record_id) FROM audit_wd_user_profile
                                 WHERE action = 'UPDATE'
                                 AND (old_job_grade != new_job_grade
                                   OR old_job_title != new_job_title
                                   OR old_limit_amount_max != new_limit_amount_max)
Inactive Signers               = SELECT COUNT(*) FROM signer WHERE status = 0
Cost Centres Inactivated       = SELECT COUNT(*) FROM infor_cost_center WHERE status = 0

DEV Note – Signer Change (Past 90 days) (key=audit_signer.id)

Fields Mapping:

GAD ID       = audit_signer.gad_id
First Name   = audit_signer.gad_id -> wd_user_profile.first_name
Last Name    = audit_signer.gad_id -> wd_user_profile.last_name
Action       = audit_signer.action (INSERT/UPDATE/DELETE)
Old BU       = audit_signer.old_bu_name
New BU       = audit_signer.new_bu_name
Old Status   = audit_signer.old_status (1=Active, 0=Inactive)
New Status   = audit_signer.new_status (1=Active, 0=Inactive)
Changed By   = audit_signer.change_by
Change Date  = audit_signer.change_date

Filter: WHERE change_date >= date('now', '-90 days')
