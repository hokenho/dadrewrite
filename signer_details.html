DEV Note – DAD Change Request (key=signer_req.id)

Fields Mapping:

Request ID        = from url parameter (reqid=DADREQ100005)
Request Date      = signer_req.req_date
Requester         = signer_req.submitter
Request Status    = signer_req.status (NULL=Pending, 0=Rejected, 1=Approved)

Approval:
AVP Approver      = signer_req.approver_avp_gad_id
AVP Result        = signer_req.approver_avp_result (NULL=Pending, 0=Reject, 1=Approve)
AVP Reason        = signer_req.approver_avp_reason
TSA Approver      = signer_req.approver_tsa_gad_id
TSA Result        = signer_req.approver_tsa_result (NULL=Pending, 0=Reject, 1=Approve)
TSA Reason        = signer_req.approver_tsa_reason
Status Reason     = signer_req.status_reason

Approval Modes (URL param: mode=):
  approval_avp → AVP Result (dropdown) + AVP Reason (text) editable
  approval_tsa → (future) TSA Result + TSA Reason editable

DEV Note – Signer Profile

Existing Signer mode (key=signer.gad_id):

GAD ID              = from URL parameter
Last Name           = signer.gad_id -> user_profile.last_name
First Name          = signer.gad_id -> user_profile.first_name
Business Unit       = signer.bu_id -> business_unit.name
Signers Cost Center = signer.gad_id -> user_profile.signer_cc
Job Level/Job Grade = signer.gad_id -> user_profile.job_level_id -> job.job_grade
Job Title           = signer.gad_id -> user_profile.job_level_id -> job.job_title
Employee No.        = signer.gad_id -> user_profile.employee_id
Pickup Cheques      = signer.pickup_cheque
Temporary           = signer.temp
Temporary Start Date     = signer.temp_start_date
Temporary End Date       = signer.temp_end_date
Status              = signer.status

New Signer mode (gad_id NOT in signer table):

Use user_profile directly when signer record does not exist.
GAD ID              = from URL parameter
Last Name           = user_profile.last_name
First Name          = user_profile.first_name
Business Unit       = business_unit.name
Signers Cost Center = user_profile.signer_cc
Job Level/Job Grade = user_profile.job_level_id -> job.job_grade
Job Title           = user_profile.job_level_id -> job.job_title
Employee No.        = user_profile.employee_id
Pickup Cheques      = Y/N
Temporary           = Y/N
Temporary Start Date     = Date Picker
Temporary End Date       = Date Picker
Status              = Active/Inactive

DADREQ mode (key=signer_req.gad_id):

- Editable fields (pickup_cheque, temp, temp_start_date, temp_end_date, status)
Old data = signer_req.source_data (in JSON format)
New data:
  GAD ID              = signer_req.gad_id
  Pickup Cheques      = signer_req.pickup_cheque
  Temporary           = signer_req.temp
  Temporary Start Date     = signer_req.temp_start_date
  Temporary End Date       = signer_req.temp_end_date
  Status              = signer_req.status

- Uneditable fields (lookup by gad_id):
Last Name           = signer_req.gad_id -> user_profile.last_name
First Name          = signer_req.gad_id -> user_profile.first_name
Business Unit       = signer_req.bu_id -> business_unit.name
Signers Cost Center = signer_req.gad_id -> user_profile.signer_cc
Job Level/Job Grade = signer_req.gad_id -> user_profile.job_level_id -> job.job_grade
Job Title           = signer_req.gad_id -> user_profile.job_level_id -> job.job_title
Employee No.        = signer_req.gad_id -> user_profile.employee_id
