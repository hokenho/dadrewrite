DEV Note – DAD Change Request (key=req_signer.id)

Fields Mapping:

Request ID        = from url parameter (id=100005 → displays DADREQ100005)
Request Date      = req_signer.req_date
Requester         = req_signer.submitter
Request Status    = req_signer.new_status (NULL=Pending, 0=Rejected, 1=Approved)

Approval:
Approver 1 (AVP+)     = req_signer.approver1_gad_id
Approval 1 (AVP+)     = req_signer.approver1_result (NULL=Pending, 0=Reject, 1=Approve)
Approval 1 Note (AVP+) = req_signer.approver1_note
Approver 2 (TSA)      = req_signer.approver2_gad_id
Approval 2 (TSA)      = req_signer.approver2_result (NULL=Pending, 0=Reject, 1=Approve)
Approval 2 Note (TSA) = req_signer.approver2_note
Status Reason     = req_signer.status_reason

URL: signer_details.html?action=<mode>&upn=<gad_id>&id=<req_signer.id>

  1. action=new_signer    → New Signer (auto-edit, upn=<gad_id>)
  2. action=view_signer   → View Signer (read-only, upn=<gad_id>)
  3. action=update_signer → Update Signer (auto-edit, upn=<gad_id>)
  4. action=view_request  → View Request (read-only, id=<number>)
  5. action=approval1     → Approver 1 AVP+ (editable approval fields, id=<number>)
  6. action=approval2     → Approver 2 TSA (editable approval fields, id=<number>)

DEV Note – Signer Profile

URL: signer_details.html?action=<mode>&upn=<gad_id>&id=<req_signer.id>

1. action=new_signer (New Signer)

gad_id NOT in signer table. Auto enters edit mode.
Lookup from wd_user_profile directly.

GAD ID              = from URL param (upn)
Last Name           = wd_user_profile.last_name
First Name          = wd_user_profile.first_name
Business Unit       = dropdown (infor_business_unit.name)
Signers Cost Center = wd_user_profile.signer_cost_center
Job Level/Job Grade = wd_user_profile.job_level_id -> wd_job_level.job_grade
Job Title           = wd_user_profile.job_level_id -> wd_job_level.job_title
Employee No.        = wd_user_profile.employee_id
Pickup Cheques      = Y/N (editable)
Status              = Active/Inactive (editable)

2. action=view_signer (View Signer)

gad_id in signer table. Read-only view.

GAD ID              = from URL param (upn)
Last Name           = signer.gad_id -> wd_user_profile.last_name
First Name          = signer.gad_id -> wd_user_profile.first_name
Business Unit       = signer.bu_id -> infor_business_unit.name
Signers Cost Center = signer.gad_id -> wd_user_profile.signer_cost_center
Job Level/Job Grade = signer.gad_id -> wd_user_profile.job_level_id -> wd_job_level.job_grade
Job Title           = signer.gad_id -> wd_user_profile.job_level_id -> wd_job_level.job_title
Employee No.        = signer.gad_id -> wd_user_profile.employee_id
Pickup Cheques      = signer.pickup_cheque
Status              = signer.status

3. action=update_signer (Update Signer)

Same data source as view_signer. Auto enters edit mode.

GAD ID              = from URL param (upn)

  GAD ID              = req_signer.gad_id
  Pickup Cheques      = req_signer.new_pickup_cheque
  Status              = req_signer.new_status

- Lookup fields (by gad_id):
Last Name           = wd_user_profile.last_name
First Name          = wd_user_profile.first_name

Data Validation (on Submit for Review):

Signing Limit Authorizations (per row):
1. Datalist fields: Country (Territory), Policy Category, Currency, Approval Cost Center
   - Value must match an active option (status=1) from the source table
   - Country (Territory): wd_territory.country_code WHERE status=1
   - Policy Category: gdas_policy.category WHERE status=1
   - Currency: infor_currency.currency WHERE status=1
   - Approval Cost Center: infor_cost_center.name WHERE status=1
2. Dropdown fields: Exception, Temporary, System
   - Constrained by select options (no free-text)
3. Date fields: Temporary Start Date, Temporary End Date
   - Must be valid date (YYYY-MM-DD) or empty
4. Free text fields: Business Rationale, Business Controls, Accounts Restriction
   - No validation
5. Country + Policy Category combination must exist in gdas_policy table
   - Lookup: gdas_policy.country_code + gdas_policy.category (status=1)
6. Limit Amounts must not exceed gdas_policy.threshold_amount
   - Only checked when Country + Policy Category combination is valid
