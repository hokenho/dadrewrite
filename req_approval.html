Actions:

DEV Note – Search Request

Fields mapping (key=signer.gad_id):

Request ID = free text input
Date Submitted = Date picker
Submitted By = free text input
Submitted For = free text input
Request Status = Dropdown (Open/Complete/Reject/Cancel)
Approval (AVP+) = Dropdown (Pending/Approved/Rejected) — shown in both modes
Approval (TSA) = Dropdown (Pending/Approved/Rejected) — shown in mode=approver2 only

DEV Note – Results

Fields mapping (key=req_signer.id):

Results limited to latest 90 rows sorted by Date Submitted DESC.

Request ID = req_signer.id
Date Submitted = req_signer.req_date
Submitted By = req_signer.submitter
Submitted For = req_signer.gad_id
Approval (AVP+) = req_signer.approver1_result (mode=approver1)
Approval (TSA) = req_signer.approver2_result (mode=approver2)
Request Status = req_signer.new_status (NULL=Pending, 0=Rejected, 1=Approved)

mode=approver1 → row click → signer_details.html?action=approval1&id={id}
mode=approver2 → row click → signer_details.html?action=approval2&id={id}
