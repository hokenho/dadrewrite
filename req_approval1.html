DEV Note – Results

Fields mapping (key=req_signer.id):

Request ID = req_signer.id
Date Submitted = req_signer.req_date
Submitted By = req_signer.submitter
Submitted For = req_signer.gad_id
Approve (AVP+) = req_signer.approver1_result (NULL=Pending, 0=Rejected, 1=Approved)
Request Status = req_signer.status (NULL=Pending, 0=Rejected, 1=Approved)

Row click → signer_details.html?action=approval1&id={id}
Opens in approval mode with Approval 1 Result and Approval 1 Reason editable.
