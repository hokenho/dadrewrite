DEV Note – Results

Fields Mapping (key=user_profile.gad_id):

GAD ID       = COALESCE(user_profile.gad_id, user_access.gad_id)
First Name   = user_profile.first_name (empty if not in user_profile)
Last Name    = user_profile.last_name (empty if not in user_profile)
Workday User = Y if gad_id exists in user_profile, else N
DAD User     = Y if gad_id exists in user_access, else N
Access       = user_access.access ('No Access' if not in user_access)
