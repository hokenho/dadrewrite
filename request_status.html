DEV Note – Search Request

Fields mapping (key=signer.gad_id):

Request ID = free text input
Date Submitted = Date picker

DEV Note – Results

Fields mapping (key=req_signer.id):

Request ID = req_signer.id
Date Submitted = req_signer.req_date
Submitted By = req_signer.submitter
Submitted For = req_signer.gad_id
Approve (AVP+) = req_signer.approver1_result (NULL=Pending, 0=Rejected, 1=Approved)
Approve (TSA) = req_signer.approver2_result (NULL=Pending, 0=Rejected, 1=Approved)
Request Status = req_signer.new_status (NULL=Pending, 0=Rejected, 1=Approved)

Approval:
AVP Approver = req_signer.approver1_gad_id
AVP Result = req_signer.approver1_result (NULL=Pending, 0=Reject, 1=Approve)
AVP Note = req_signer.approver1_note
TSA Approver = req_signer.approver2_gad_id
TSA Result = req_signer.approver2_result (NULL=Pending, 0=Reject, 1=Approve)
TSA Note = req_signer.approver2_note
Status Reason = req_signer.status_reason
