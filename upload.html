Validation Logic – Signer Profile

CSV Columns:

Action (UPDATE/DELETE/ADD), GAD ID (key), Business Unit,
Pickup Cheques, Temporary, Temporary Start Date, Temporary End Date

Validation Rules:

1. Action must be UPDATE, DELETE, or ADD
   - DELETE rows skip all other validations

2. Business Unit must match an active value in infor_business_unit table (status=1)

3. Pickup Cheques must be Y or N

4. Temporary must be Y or N

5. Temporary Start Date / End Date:
   - Must be valid date format (YYYYMMDD or YYYY-MM-DD)
   - Both must be filled or both must be empty
   - End Date must be on or after Start Date

6. If Temporary = N:
   - Both Start Date and End Date must be empty

Validation Logic – Signer Limit

CSV Columns:

Action (UPDATE/DELETE/ADD), Approval ID (key), GAD ID,
Country (Territory), Policy Category, Limit Amounts, Currency,
Approval Cost Center, Exception, Temporary,
Temporary Start Date, Temporary End Date,
Business Rationale, Business Controls, Accounts Restriction

Validation Rules:

1. Action must be UPDATE, DELETE, or ADD
   - DELETE rows skip all other validations

2. Country (Territory) must match an active value in wd_territory table (status=1)

3. Policy Category must match an active value in gdas_policy table (status=1)

4. Currency must match an active value in infor_currency table (status=1)

5. Approval Cost Center must match an active value in infor_cost_center table (status=1)

6. Exception, Temporary, Business Rationale, Business Controls
   must be Y or N

7. Accounts Restriction: free text (no validation)

8. Temporary Start Date / End Date:
   - Must be valid date format (YYYYMMDD or YYYY-MM-DD)
   - Both must be filled or both must be empty
   - End Date must be on or after Start Date

9. If Temporary = N:
   - Both Start Date and End Date must be empty

10. Country + Policy Category combination must exist
    in gdas_policy table (country_code + category, status=1)

11. Limit Amounts must not exceed gdas_policy.threshold_amount
    for the matched Country + Policy Category
