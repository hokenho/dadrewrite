DEV Note – Search Audit Log (table=audit_gdas_policy)

Filter Fields:

Change Date       = audit_gdas_policy.change_date (exact match)
Change Type       = audit_gdas_policy.action (exact match: INSERT/UPDATE/DELETE)
Changed By        = audit_gdas_policy.change_by (LIKE)
Countries         = old_country_code OR new_country_code (LIKE)
Policy Category   = old_category OR new_category (LIKE)
Description       = old_description OR new_description (LIKE)
System Type       = old_system OR new_system (LIKE)
Manual Approval   = old_manual_approval OR new_manual_approval (BIT match)
Status            = old_status OR new_status (BIT match)

Behavior:

Apply Filter re-queries database with SQL WHERE clauses, returns TOP 50.
Clear resets all filters and re-queries TOP 50 unfiltered.
Enter key triggers filter from any input field.

DEV Note – Audit Log: Policies Categories (table=audit_gdas_policy)

Fields Mapping:

Change Date       = audit_gdas_policy.change_date
Change Type       = audit_gdas_policy.action
Changed By        = audit_gdas_policy.change_by
Row               = Before / After / New / Deleted label
Countries         = old_country_code / new_country_code
Policy Category   = old_category / new_category
Description       = old_description / new_description
System Type       = old_system / new_system
No. of Approvals  = old_approval_count / new_approval_count
Threshold Amount  = old_threshold_amount / new_threshold_amount
Manual Approval   = old_manual_approval / new_manual_approval
Status            = old_status / new_status

Display Rules:

Source: audit_gdas_policy table
Display: TOP 50 audit groups (SQL LIMIT 50, sorted by change_date DESC, id DESC)
Filtering: Re-queries DB with WHERE clauses, returns TOP 50 of filtered results
Export: Runs same query WITHOUT LIMIT, exports all matching rows to CSV

Row Styles:

INSERT = green background, green badge, "New" label
UPDATE = Before (grey text) / After pair, yellow highlight on changed cells
DELETE = red background, red badge, strikethrough text, "Deleted" label
