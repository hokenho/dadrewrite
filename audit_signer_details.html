DEV Note – Search Audit Log (tables=audit_signer, audit_signer_limit)

Filter Fields:

Change Date    = change_date (exact match)
Change Type    = action (exact match: INSERT/UPDATE/DELETE)
Changed By     = change_by (LIKE)
Both tables are always filtered by gad_id from URL ?upn= parameter.

Behavior:

Apply Filter re-queries both tables with SQL WHERE clauses, returns TOP 50.
Clear resets all filters and re-queries TOP 50 unfiltered.
Enter key triggers filter from any input field.

DEV Note – Audit Log: Signer (tables=audit_signer, audit_signer_limit, signer_limit)

Summary Table:

Groups audit events by (change_date, change_by) from a UNION of:
  - audit_signer WHERE gad_id = ?upn
  - audit_signer_limit WHERE gad_id = ?upn
Shows TOP 50 groups sorted by change_date DESC.
Change Type shows all distinct actions in that group.

Click to Open Popup:

Clicking a summary row opens a popup modal showing full snapshot:

1. Signer Profile (from audit_signer + signer)
   Shows Before/After for UPDATE, New for INSERT, Deleted for DELETE.
   If no profile change at this time: shows current signer data
   from signer table (JOINed with infor_business_unit) with
   UNCHANGE badge — full snapshot view.

2. Signing Limit Authorizations (from audit_signer_limit + signer_limit)
   Shows changed limits with Before/After rows (UPDATE/INSERT/DELETE).
   Also shows UNCHANGED limits (from current signer_limit table,
   excluding signer_limit_ids that have audit entries at this time)
   marked with grey UNCHANGE badge.

   This gives a full snapshot view of all limits at audit time.

Row Styles (in popup):

INSERT    = green background, green badge, "New" label
UPDATE    = Before (grey) / After pair, yellow highlight on changed cells
DELETE    = red background, red badge, strikethrough text, "Deleted" label
UNCHANGE  = grey background, blue-grey badge, current values
